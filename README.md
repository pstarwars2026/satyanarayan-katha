# Satyanarayan Katha

A free, illustrated Satyanarayan Katha app for iPad and iPhone, with Gujarati narration, Sanskrit shlokas and two voices. It works offline. It is a companion to the [Sanskriti AI aur Travel](https://www.youtube.com/channel/UCltArUjYANBr4EmnvROwXNA) YouTube channel.
